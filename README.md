# Методическая мастерская

Сайт для GitHub Pages: https://edutools.ru/

Три проекта: генератор карточек по системам счисления, симулятор КуМир с конструктором заданий, симулятор сложности алгоритмов.

## Публикация

1. Загрузите содержимое этой папки в корень репозитория `kruzzz/metod` (ветка `main`), включая `.github/workflows/pages.yml`.
2. Откройте репозиторий → Settings → Pages → Source → **GitHub Actions**.
3. Во вкладке Actions откройте **Publish GitHub Pages**. Если первый запуск уже завершился ошибкой до включения Pages, нажмите **Re-run all jobs** или **Run workflow**.
4. После успешного выполнения сайт доступен по адресу выше. Каждый push в main автоматически обновляет сайт.

## Локальная работа

Требуется Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000/.

```sh
npm test
npm run build
```

Готовые статические файлы находятся в `out/`. Не загружайте `node_modules`, `.next`, `.git` или `out` вручную в исходный репозиторий: Actions собирает сайт самостоятельно.

## Изменения

- Главная: `app/page.tsx`.
- Карточки: `app/cards/page.tsx`, оформление и печать: `app/globals.css`.
- КуМир и его задания: `public/kumir/`.
- Сложность алгоритмов: `public/complexity/`.

Сайт настроен на корень домена edutools.ru. В Settings → Pages → Custom domain укажите edutools.ru. DNS настраивается отдельно в reg.ru.

Сайт не требует сервера или ключей API. Прогресс сохраняется в браузере.
